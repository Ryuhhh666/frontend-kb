# frontend-kb

个人前端知识库：前端技术 + 电商业务沉淀。

## 目录结构

```
frontend-kb/
├── skills/            # 本项目的 skills 指引
├── frontend/          # 前端技术
│   ├── html-css/
│   ├── javascript/
│   ├── framework/     # Vue / React 等
│   ├── engineering/   # 构建、性能、工程化
│   └── browser/
├── ecommerce/         # 电商业务
│   ├── basics/        # 领域概念与术语
│   ├── scenarios/     # 购物车、下单、支付、营销等
│   └── architecture/  # 电商前端架构实践
├── notes/             # 读书笔记、文章摘录
└── snippets/          # 代码片段
```

## 约定

- 文件命名：小写中划线（如 `event-loop.md`）
- 每篇笔记包含：概述 → 核心内容 → 实践/踩坑 → 参考
- 持续更新，随做随记
