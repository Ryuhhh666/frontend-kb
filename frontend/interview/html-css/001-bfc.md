# BFC 块级格式化上下文

## 题目
简述 BFC（块级格式化上下文）是什么，它解决了哪些常见布局问题？

## 解析
BFC 是 CSS 渲染中的一块独立区域，内部元素的布局不影响外部。触发方式包括：根元素、`float` 非 none、`position: absolute/fixed`、`display: inline-block / flow-root / flex`、`overflow: 非 visible`。它主要解决：1) 父元素高度塌陷（清除浮动）；2) 相邻元素 margin 合并；3) 浮动元素遮挡文字。

## 知识点回顾
- 盒模型与常规流 / 浮动 / 定位三种布局方式
- BFC、IFC 等格式化上下文的概念与触发条件
- `display: flow-root` 是无副作用创建 BFC 的现代方式
- margin 塌陷与合并规则
