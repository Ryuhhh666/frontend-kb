# HTTP 版本演进

## 题目
HTTP/1.1、HTTP/2、HTTP/3 的主要区别是什么？

## 解析
- **HTTP/1.1**：文本协议，持久连接但存在队头阻塞（一个 TCP 连接上请求需按序响应），浏览器靠并发多个 TCP 连接缓解；- **HTTP/2**：二进制分帧、多路复用（一个 TCP 连接并发多个流）、头部压缩（HPACK）、服务器推送；解决了 HTTP 层队头阻塞，但 TCP 层丢包仍会阻塞所有流；- **HTTP/3**：基于 QUIC（UDP），彻底解决 TCP 队头阻塞，连接建立更快（0/1 RTT），内置 TLS 1.3，支持连接迁移（切换网络不断连）。

## 知识点回顾
- TCP 三次握手 / 四次挥手过程及原因
- HTTPS 握手流程与证书校验
- 队头阻塞在 HTTP 层与 TCP 层的不同表现
- 缓存策略：强缓存与协商缓存
